Bluetooth

[ Pengertian ]

Bluetooth adalah spesifikasi industri untuk jaringan kawasan pribadi nirkabel (WPAN). Teknologi ini memfasilitasi koneksi dan pertukaran data antar perangkat dalam jarak yang relatif dekat.

[ Uraian ]

Beroperasi pada pita frekuensi radio UHF 2.4 GHz, menggunakan teknologi frequency-hopping spread spectrum untuk menghubungkan perangkat seluler, komputer, dan perangkat IoT tanpa kabel fisik.

[ + Kelebihan ]

  • Sangat praktis dan mudah dikonfigurasi.
  • Gratis, tidak memerlukan biaya operator.
  • Konsumsi daya relatif rendah (terutama versi BLE).
  • Kompatibel dengan hampir semua perangkat pintar.

[ - Kekurangan ]

  • Jangkauan transmisi terbatas (umumnya ~10 meter).
  • Kecepatan transfer data lebih lambat dibanding WiFi.
  • Keamanan rentan jika diakses di tempat umum tanpa pairing yang kuat.
📡

Wi-Fi

[ Pengertian ]

Wi-Fi (Wireless Fidelity) adalah teknologi jaringan nirkabel yang memungkinkan perangkat elektronik terhubung ke jaringan lokal (WLAN) atau internet.

[ Uraian ]

Berdasarkan standar protokol jaringan IEEE 802.11, Wi-Fi menggunakan gelombang radio (frekuensi 2.4 GHz dan 5 GHz) untuk mentransmisikan informasi berkecepatan tinggi melintasi jarak menengah.

[ + Kelebihan ]

  • Kecepatan transfer data yang sangat tinggi.
  • Jangkauan lebih luas dibandingkan Bluetooth.
  • Mampu menghubungkan banyak perangkat secara bersamaan.
  • Biaya implementasi jaringan skala besar yang efisien.

[ - Kekurangan ]

  • Membutuhkan perangkat keras tambahan (Router/Access Point).
  • Konsumsi daya pada perangkat seluler lebih boros.
  • Kualitas sinyal rentan terhadap penghalang fisik (tembok tebal) dan interferensi.
🔌

Kabel Data

[ Pengertian ]

Kabel data adalah media fisik terpandu yang digunakan untuk menghubungkan ponsel pintar dengan perangkat lain (seperti PC/Laptop) guna mentransmisikan data.

[ Uraian ]

Pada ponsel, koneksi ini umumnya menggunakan antarmuka USB (Micro-USB, USB Type-C, atau Lightning). Data ditransmisikan melalui sinyal listrik di dalam kabel tembaga murni.

[ + Kelebihan ]

  • Stabilitas koneksi paling tinggi, tidak terpengaruh sinyal luar.
  • Kecepatan transfer data maksimal dan sangat cepat.
  • Bisa berfungsi ganda: transfer data sekaligus mengisi daya (charging).
  • Keamanan data sangat tinggi (fisik/lokal).

[ - Kekurangan ]

  • Mobilitas sangat terbatas karena panjang kabel.
  • Port atau kabel fisik rawan rusak (putus/korsleting).
  • Kurang praktis jika harus menghubungkan banyak perangkat.
